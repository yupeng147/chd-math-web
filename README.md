# 数学分析交互式知识图谱

## 项目背景
长安大学挑战杯科技发明制作B类项目，基于现有网站新增 GeoGebra 数分交互式可视化模块。

## 功能说明
- 首页：动态网状关系图谱（中心“数学分析”向外延伸章节、小节、知识点）。
- 交互：鼠标滚轮缩放、拖拽画布、节点高亮、末级节点跳转画板。
- 画板页：嵌入 GeoGebra 交互式画板，展示对应知识点动画。

## 目录结构
- `index.html`：首页图谱
- `css/style.css`：样式
- `js/graph.js`：图谱数据与逻辑
- `pages/demo.html`：画板嵌入页
- `README.md`：本说明

## 运行方式
直接用浏览器打开 `index.html`（建议使用 VSCode Live Server）。
